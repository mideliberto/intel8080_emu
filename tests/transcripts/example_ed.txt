# An editor session is one '<' step: each line typed with \r, the last one q. The
# step ends at the monitor's "> " after q. The editor echoes what it reads and
# prompts with "*". Its files go through storage ports 08-0F, driven by the program.
# Make a text, insert before line 2, delete line 4, append, write, clear, read back.
