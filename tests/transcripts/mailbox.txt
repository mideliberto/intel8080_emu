# Service Mailbox from the monitor (DEVICE_SPECS 8) and T (MONITOR_SPEC 6.15).
# Format: tests/monitor_tests.rs header. Runs on hardware with the Pi clock set
# (NTP or RTC; unset, TIME is 83): nothing here depends on the time's value.
#
# T's own output is a time, which an exact transcript can't match; the shape
# NNNN-NN-NN NN:NN:NN, the port sequence and Service error are Rust-side in
# monitor_tests.rs (Time). This file covers what is exact: the mailbox through I and O,
# and the state T leaves behind.
