# G [addr] (MONITOR_SPEC 6.5) and the G return contract (section 8). Boot RAM is
# HLT junk, so a G that runs anything by mistake halts the harness and fails.

# A present but invalid address is an error and runs nothing (0100 is still junk).
> G ZZ

> G 01ZZ
Invalid address
> G 10100
Invalid address
> G 0100,
Invalid address
