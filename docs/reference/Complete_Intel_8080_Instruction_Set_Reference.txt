# Intel 8080 Instruction Set - Complete Opcode Table

## Instruction Format Key
- **Binary Pattern**: Shows the bit encoding (DDD = dest register, SSS = source register, RP = register pair)
- **Bytes**: Instruction size in bytes
- **Cycles**: Clock cycles (may vary for conditional branches)
- **Flags**: Which flags are affected (S=Sign, Z=Zero, A=Aux Carry, P=Parity, C=Carry)

## Register Encoding
| Code | Register | Code | Register Pair |
|------|----------|------|---------------|
| 000  | B        | 00   | BC           |
| 001  | C        | 01   | DE           |
| 010  | D        | 10   | HL           |
| 011  | E        | 11   | SP (or PSW)  |
| 100  | H        |      |              |
| 101  | L        |      |              |
| 110  | M (memory at HL) |  |          |
| 111  | A        |      |              |
