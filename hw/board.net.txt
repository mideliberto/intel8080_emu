# hw/board.net.txt - the 8080 board netlist: the only home of pin numbers (HARDWARE_BUILD 2.2).
# ARCHITECTURE.md 6 is normative for the circuits and rules; tests/netlist_tests.rs checks this
# file against it, pad by pad, and writes the KiCad netlist hw/board.kicad.net from it.
#
# Format: '#' to end of line is a comment. Blank lines are ignored.
#   part <ref> <type> <value>      footprint and pin table come from the type (tests/netlist_tests.rs)
#   <pad> <pinname> <net>          one line per pad, every pad of the footprint exactly once
# <net> NC = explicitly unconnected. '~' as <pinname> only for types whose table has no names.
# Rails: GND +5V +12V -5V +3V3_PI +5V_IN (the jack side of the reverse-polarity FET).
# Active-low nets end in _N. Values are generic part names; order codes live in docs/PARTS_ORDER.md.
